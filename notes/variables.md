# Variables
A variable is a type of container we create to store information to be accessed later. Every variable
in Java has **three things**:
- a type
- a name
- a value

# Rules & Mechanics
- Can't have incompatible data inside
- must be declared before use
- type must be specified using a keyword
- access to variable depends on scope
- can't use keywords as a name


# Example:
- **int age**;

# Why is this important
Variables allow my program to:
- remember information
- perform calculations
- store users input
- control logic
- build on more complex structers (objects, arrays, list, etc.)

# Declaration vs. Initialization:
**Declaration** - Tells Java the variable exists:
- **int** age;

**Initialization** - Giving the variable a value:
- age = **25**;

**Declaration & Initialization**
- **int age = 25**;

## Naming Rules:
- must start with a letter, _, or $
- Can't start with a number
- Can't have spaces
- They are case-sensitive
- Should be descriptive

## When to use variables:
- When you need to reuse a value
- A value changes over time
- Wehn a value comes from user input
- When a value is part of calculation

## Common Mistakes:
- forgetting to initialize a variable
- using the wrong type
- naming variables poorly
- mixing = (assignment) with == (comparison)
- forgetting the "L" or "f" suffix for longs and floats

## Summary:
Variables are teh building blocks of Java programs. The store data, allow calculations, and make code
dynamic. Understanding variables sets the foundation for:
- operators
- control flow
- methods
- objects
- classes
- data structures
