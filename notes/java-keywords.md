# Java Keywords
Java keywords are **reserved words** that have special meaning in the Java language.

---

## Rules & Mechanics:
- Always lowercase
- Can't be used as naming conventions
- Can't be changed or redefined

---

## Why is this Important:
Keywords tell the complier what kind of data I am using or how I am trying to structure my code. Specifically it helps:
- define classes
- declare variables
- control logic
- structure methods
- handles exceptions
