# Classes Part 1
This folder contains the example code on how to create and use other classes in addition to your main class.  
The goal of this lesson is to understand OOP, and how to make fields and methods inside other classes to implement **encapsulation**.

---

## 📘 Concepts Demonstrated

### 1. Object Creation Creation
* Must first create an **class**, meaing you must fist "**instantiate**" a class
* The use of the keyword `new`

### 2. Private Instance Fields
* Creating fields and using the `private` access modifer.
* Used for **encapsulation** (see `object-oriented-programming.md`).
* You can choose assign a value these fields.
* For the most part you should make the fields `private`.

### 3. Getters & Setters
* By making fields `private` you limit who can access it, so you need a way to change the contents if needed.
* By using **Getters** you can return values inside the instance fields
* By using **Setters** you can assign values to the instance fields
* You can add additional validation inside **setters** to further restrict what information to is provided.
