# Switch Lesson
This folder contains the example code used in Tim Buchalka’s *Java Programming Masterclass* lesson on the **switch statement**.  
The goal of this lesson is to understand the use cases of a `switch` statement, how it compares to an `if-else` statement. 
This lesson also shows the two different kinds of `switch` statements: `Traditional` and the `Enhanced`.

---

## 📘 Concepts Demonstrated

### Traditional 
- Comparing one value against multiple
- How to return a value from it using method
- Using a `{}` to run multiple statements based on the value
- Importantce of the `default` keyword

### Enhanced
- Showing how if differs from the `Traditional` by way of the `switch expression arrow` (->)
- Using `{}` to run multiple statements based on the value
- `default` keyword is replaced with `yield` when returning a value inside `{}`

### Basic Conditional Logic
- Simple `if` statements
- Used to show difference between `if-else` and `switch` statements when comparing a single value
