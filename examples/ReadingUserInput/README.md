# Reading User Input
This folder contains the example code on how to **read user input/parse numeric values from `Strings`**.  
The goal of this lesson is to understand the use cases of `System.console` and `Scanner`, as well as how the two of them differ.

---

## 📘 Concepts Demonstrated

### 1. System.console()
* Can't be run in IDE's, causing them to return `null`.
* Can add prompts directly using `System.console.readline()`.

### 2. Scanner
* In order to be used `import java.util.Scanner;` must be typed at the top of the class.
* You must first instantiate the **Scanner** class using the keyword `new`.
* To read input from the console you must use the built-in Java method for **Scanner** `nextLine()`.

### 3. Parsing Numeric Values
* In order to parse `Strings` to their numeric counterparts you must use their Wrapper class as well as their built-in methods.

### Basic `Try/Catch` statement
* Briefly went over the use of the `try/catch` statement
* Useful to catching exceptions (errors) you expect to happen from you code.
